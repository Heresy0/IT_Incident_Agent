# 固定评测资料：内部模拟方案

以下内容由项目维护者编写，A/B/C 是虚构方案，仅用于固定资料评测，不描述真实商业产品。各段同时作为人工标注的支持片段。

## A：自建方案

A 支持私有部署，提供 Python SDK。A 的应用代码采用 Apache-2.0 许可。A 需要团队自行维护应用服务和 PostgreSQL。A 没有可视化工作流编辑器。

## B：托管方案

B 仅支持公有云托管，不提供私有部署。B 提供 HTTP API 和可视化工作流编辑器。B 的模拟套餐为每月 2000 元；超过套餐额度的费用没有在资料中说明。B 的数据保留期为 30 天。

## C：本地方案

C 支持本地 Docker 部署，依赖 PostgreSQL 和 Milvus。C 的管理员能够导入 UTF-8 Markdown 与 TXT 文档。C 不支持 OCR。C 的示例接口限流为每分钟 60 个请求；资料没有提供并发吞吐测试。

## 团队约束

团队有 5 名研发人员，主要使用 Python。内部文档要求私有部署。首轮验证窗口为 14 天，每月预算上限为 2000 元。资料没有说明这笔预算是否包含服务器和模型费用。

## D：旧版本资料

这份资料记录模拟方案 C 的旧测试分支，该分支曾提供 OCR 预览功能。资料没有说明该分支与目前方案 C 的版本对应关系，不能据此判定当前版本支持 OCR。以上内容仅用于版本冲突评测。
