## 一条命令复现

安装根目录锁定依赖后，在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe scripts/showcase_incident.py
```

Linux/macOS 或已激活虚拟环境时：

```sh
python scripts/showcase_incident.py
```

不需要模型 Key、访问令牌、PostgreSQL、Docker 或另一个项目。脚本没有 live 开关，不读取 `.env`。输出保存到 `output/showcase/<运行批次>/`；可直接打开 `index.html` 查看，也可读取 `summary.json` 和三份 JSON/Markdown 原始控制报告。重复执行会创建新批次，避免覆盖历史结果。

脚本同时运行已有同预算模拟对照、五类 Harness 约束的七个测试，以及内存中的模拟审批闭环。遇到与预期不符的结果返回非零状态，不通过提高预算消除失败。

## 一个真实业务闭环

来源：本地知识库试点过程与用户在会话中的成功反馈，属于用户确认案例。公开描述使用业务概念，不公开本地登记、身份、容器名称或真实数据。

1. 用户反馈索引任务排队；当前观测出现活跃 Worker 为 0、队列深度大于 0，并取得停止事件。
2. Agent 读取工单范围内观测，形成有条件的处置建议；这些现象说明消费者缺失，不能单独证明停止的深层原因。
3. 人工选择支持动作的当前证据，创建登记目标的重启提案，检查适用条件、风险和恢复验证方法。
4. operator 审批后另行确认执行。后端执行器仅操作登记目标，检查幂等、健康和症状恢复。
5. 用户反馈修复成功，知识库文档已入库。正式闭单与检索质量未另行核验。

这是项目业务落地证据，不用于统计整体修复成功率。命令行展示还会运行模拟闭环：零真实写操作，一次模拟执行；重复相同执行请求返回原结果，不重复执行；修复 verified 后工单仍需人工确认。

## 简历表述与面试边界

可按个人实际参与情况选择以下表述，不添加未测量的提升百分比：

- 基于 LangGraph 实现五角色故障诊断编排，支持模型选择只读工具、证据驱动诊断、逐项复核及一次有界补查。
- 构建统一执行 Harness，约束工具权限与服务范围，管理调用预算、去重和有限重试，使用结构化契约与来源引用校验保留可追溯运行记录。
- 实现人工审批与受限执行器的修复闭环，并建立同预算单／多 Agent 对照与失败案例分析；本地 Worker 恢复及文档入库由用户确认。

面试时能直接指出：模型选择工具的位置是 Investigation 循环；路由执行在 LangGraph，业务协调在 Collaboration；权限与计数在程序侧，不依赖提示词承诺。五角色不是五种模型，复核不是独立真值。对照只有小样本，尚未证明多角色准确率提升。SSE 回放不等于 checkpoint 恢复。
