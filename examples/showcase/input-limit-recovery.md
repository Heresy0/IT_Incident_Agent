# 单次模型输入上限提高到 48000 字符

`Limits.input_chars` 默认从 28000 提高到 **48000 字符**，包含系统提示、schema、证据与对话历史，不是token数。标准流程仍默认legacy；调用次数、工具次数、收尾预留、模型输出额度、证据/范围/审批校验保持原设置。输出/超时增加只沿用此前评测配置，不改变业务默认2200token/30秒。

此前消费者暂停例的有效Reviewer已经授权H3修稿，但 `RevisionDiagnosisSelection` 输入35844字符，被28000门禁拒绝。本次默认48000留出余量，原始失败档案不改写。

环境预算入口可配置：

```dotenv
INCIDENT_MAX_INPUT_CHARS=48000
```

`Limits.from_env()` 接受4000至128000，空值用48000，超出范围截到边界；非法非数字值拒绝。显式传入的 `Limits` 优先，固定历史评测需要按其原始冻结版本复现。已运行的后端需重新启动以读取新代码/配置。

本轮三例都没有交付有效末次复核，也没有进入修稿分流，因此不能宣称原35844字符修稿链路已被真实模型完整走通，更不能宣称提高额度提升了诊断质量。参数、引用和反证契约仍会阻断；预算扩大只解决容量门禁。
