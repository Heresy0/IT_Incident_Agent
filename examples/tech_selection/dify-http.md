# Dify HTTP 请求能力资料笔记

来源：[官方 HTTP Request 文档](https://docs.dify.ai/en/cloud/use-dify/nodes/http-request)。核对日期：2026-10-07；该页面为 cloud 文档，所选自部署版本是否一致待核对。

这是人工整理的摘要，不是原文或实际连接结果。文档介绍工作流通过 HTTP 节点访问 API，配置 URL、请求头、查询参数和请求体，引用工作流变量，并设置超时和认证。

这能支持存在 HTTP 集成能力的结论，不能证明目标自部署版本能访问企业内部接口；网络可达性、鉴权、出站限制和企业证书应在 PoC 中验证。
