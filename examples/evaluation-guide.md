## 重构收益怎样表达

冻结配对实验中，两版使用相同模型和预算。可引用以下已记录结果：

| 指标 | 旧版 → v2 | 含义 |
| --- | --- | --- |
| 最终结构／引用／审阅契约中断 | 8/22 → 0/22 | 该组端到端实验的最终协议中断减少；不等于所有场景永无解析错误 |
| 平均原生运行耗时 | 约 52.1 → 28.7 秒 | 该组实验约下降 45%，不作为生产延迟承诺 |
| 应覆盖观测记录取得 | 26/38 → 37/38 | 指定观测覆盖改善，不是根因准确率 |
| 单列关键记录取得 | 5/6 → 5/6 | 该项没有提升，应与覆盖指标分开陈述 |
| 公开非缓存价格估算费用 | 约下降 3.5% | 估算的小幅变化，未使用实际供应商账单证明降本 |

相同 Flash 指相同请求模型别名和设置，未证明供应商底层权重快照完全固定。配对范围包含开发案例、相关变体与重复，不是独立生产事故样本。

## 根因成功率怎样表达

另一组跨机制实验的端到端条件下，严格根因内容正确为 **21/24（87.5%）**，关键证据取得为 **24/24**。这是 **8 个构造案例，各运行 3 次**，不是 24 个独立故障。裁决来源为非盲 AI，生产准确率、独立保留集准确率和人工金标成绩均未取得。

“证据取得”表示关键原始记录进入存储，不代表模型正确理解、整合或引用。预置充分证据阶段直接提供固定的公开观测，用于研究证据整合与审阅；必须与端到端分开统计，不能用两个阶段的差直接证明调查的因果收益。

评分表中的错误确证指标有明确判定范围，不能扩写为“报告没有任何错误”。证据整合、时间范围、量纲比较和语义审阅仍有已记录问题；前端退役后 case_003 的容量论证疑点也明确登记为 AI 复核发现、待人工核验。

## 完成、交付与正确是三件事

| 指标或状态 | 能说明什么 | 不能说明什么 |
| --- | --- | --- |
| 严格根因内容正确 | 按绑定报告和指定裁决口径，根因定位内容符合参考证据 | 流程完整、没有其他错误或已修复 |
| 完整交付且根因正确 | 同时满足完成／交付口径与根因内容判定 | 生产可用性或人工已确认解决 |
| `completed` | 达到当前完成契约，形成受限诊断或状态报告 | 唯一根因被证明、服务恢复、工单关闭 |
| `partial` | 仍有执行、来源、审阅或机制支持缺口 | 报告无法保存或无法回传前端 |
| 内部审阅 `passed` | 本轮模型审阅按当前契约通过 | 外部正确性、人工金标或因果已验证 |
| 费用与延迟 | 指定实验的 Token 价格估算和计时统计 | 实际账单、线上 SLA 或跨实验可直接比较 |

## 如何核验和复现

先核对摘要中的源码、数据版本、输入阶段、模型设置、预算、分子分母和裁决来源，再按原始报告与事件哈希核验。`output/` 原档和数据库不随克隆提供；缺少原档时只能阅读已提交摘要，不能声称已重新核验原报告。
