# IT 调试前端实施记录

日期：2026-10-09。本轮目标是提供方便真实服务联调的简单页面，复用已有前端能力，不扩展完整生产页面或修复执行功能。

## 实现

- App.vue 改为 IT 调试入口：显示后端连接状态，输入Bearer令牌，调用正确的 /api/v1/auth/me，显示身份并挂载原 IncidentPanel。移除当前入口的研究、搜索及记忆界面。
- IncidentPanel.vue 保留工单CRUD、SSE、幂等启动、身份隔离的运行恢复和人工确认流程。新增登记服务下拉框、可用指标、时间快捷填充、带本地时区转换的日期输入和表单检查。默认状态核查文本不会预设故障。
- 真实工单只允许live；开发案例可使用免费脚本。预算遵循后端的模型6..16、工具1..24限制；真实诊断必须勾选本次授权并点击启动。修改预算会清除勾选。默认模型12、工具8。
- 查询运行与事件统一使用 /api/v1/runs，不再依赖旧research运行别名。刷新/断线重连不POST诊断；未收到启动响应时保留原请求key及精确预算。
- ReportView.vue 使用Vue文本插值展示标题、列表、代码及强调，不使用v-html，不执行报告中的HTML。原文、统计、结构化结果和证据仍可展开。
- Vite仅监听127.0.0.1:5174并使用strictPort。代理读取项目根目录后端配置，当前连接8002；可用INCIDENT_API_TARGET覆盖。根目录模型凭据不会暴露为浏览器环境变量。
- 复用现有依赖；没有新增依赖或改动后端API。用户现有源码、服务配置、研究归档和其他项目保留。

## 使用

后端保持运行，另开终端执行：

```powershell
cd D:\code\it_incident_agent
.\.venv\Scripts\python.exe local_run.py frontend
```

打开 http://127.0.0.1:5174/。输入本地operator token → 验证身份 → 选择enterprise-indexing → 调整问题与时间窗口 → 创建工单 → 设置预算并勾选授权 → 启动付费诊断 → 查看事件和报告。

创建工单不调用模型。令牌只在页面内存中保留，刷新后重新输入；按身份保存的工单/运行定位信息会恢复已有结果。开发案例选择免费模式即可检查完整交互。人工确认按钮仅保存实际核实的处理结果并关闭工单，不会自动执行修复。

## 验证

1. Vue TypeScript检查通过；Vite生产构建通过，19个模块，JavaScript约90 KB（gzip约35 KB）。第一次沙箱构建因Windows realpath权限失败，在正常本机权限下完成，未修改构建逻辑绕开校验。
2. 使用临时无头Edge和模拟API，验证创建工单、预算格式、显式付费授权、预算修改后的重新授权、报告HTML转义及事件回放。刷新并重新认证后恢复原报告，整个测试仅发送一次诊断POST和一次工单POST，均为模拟响应。
3. 检查令牌未写入sessionStorage；页面390px宽时无横向溢出，桌面和移动端截图已检查。截图位于忽略提交的output/frontend-debug。
4. 真实后端检查只允许GET：健康、身份、登记服务、开发案例和工单列表读取成功，页面显示enterprise-indexing。没有写业务数据库、调用真实模型或执行修复。
5. Git空白检查通过；未重复运行无关后端全量测试。

## 边界与后续

本轮运行验证的是调试交互，模拟live响应不计入模型诊断质量。真实小预算诊断仍由用户在页面显式执行。当前没有修复计划、审批、执行按钮；完整生产登录、团队管理和部署不是本轮范围。生产构建产物不自带Vite开发代理，正式部署需要静态服务器与API代理配置。

本轮启动了本项目前端开发服务器供用户立即使用；不重启用户后端，也不启动或修改知识库组件。完整操作说明见front/agent_front/README.md和README_LOCAL.md。
